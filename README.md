# Join the IndieWeb 🌱

**A practical guide to making a little corner of the internet your own.**

You don't need to be a developer, buy an expensive server, or leave every social network. You can start with one page, a few links, and something you want to share.

The [IndieWeb](https://indieweb.org/) is a community built around personal websites, ownership of your online identity and content, and publishing on your own site. The wider small web includes personal homepages, handmade sites, blogs, digital gardens, and more. These communities overlap, but neither has a required aesthetic or technology stack.

## Your first hour

1. Read the [official getting started guide](https://indieweb.org/Getting_Started).
2. Choose a hosted blog if writing matters most, or a static host if you want to design your pages yourself.
3. Publish a homepage with your name or chosen alias and a short introduction.
4. Add a link to a site you like. Write a first post if you feel like it.
5. Open your site on a phone and share its address with someone.

You can use a free subdomain to experiment. A domain you register and control is a worthwhile next step because it can follow you between hosts.

## Your first month

- [ ] Publish a personal homepage.
- [ ] Choose a stable address and set up HTTPS.
- [ ] Write a post at a permanent URL.
- [ ] Add an About page and contact method you're comfortable sharing.
- [ ] Make your work readable on mobile and with a keyboard.
- [ ] Add a blogroll and subscribe to a few feeds.
- [ ] Export or back up your site and images.
- [ ] Explore the IndieWeb community, if you want to.
- [ ] Try one optional interoperability feature when it solves a real need.

## How much technical knowledge do I need?

| Path | What you'll need | Tradeoff |
|---|---|---|
| Hosted blog | Writing, basic settings | Less maintenance, some platform limits |
| Handwritten HTML | HTML and CSS | Creative freedom, manual updates |
| Static site generator | Markdown, templates, Git and a build tool | Easier to maintain many pages, more setup |
| Self-hosted CMS | Hosting, updates, backups | More dynamic features and responsibility |

Don't treat the checklist as a test of whether you belong. Start with what you enjoy and build from there.
