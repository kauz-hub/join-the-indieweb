Chapter 04 · Field guide

4. Learn the web at your own pace

You can make a good personal website with no frameworks. Focus on things you'll actually use.

Stage Learn Build to practice
1 Files, folders, URLs, relative links Two local HTML pages that link to each other
2 Semantic HTML, headings, lists, links, images About page with descriptive image alt text
3 CSS selectors, box model, spacing, typography Your own colors and readable layout
4 Flexbox, Grid, flexible widths, media queries A layout that works on a small phone
5 Accessibility and browser devtools Keyboard navigation and visible focus
6 Markdown, Git basics, commits and deployment A small journal with version history
7 Reusable layouts, generators, feeds A blog with a feed and multiple posts
8 (optional) Microformats, Webmention, IndieAuth Structured profile and connected posts

Go at your pace. One week per stage is a possible schedule, not a deadline.

Learn from good references

  • MDN Learn Web Development: structured HTML, CSS, JavaScript and accessibility lessons.
  • freeCodeCamp: guided coding exercises.
  • The Odin Project: project-based web development curriculum.
  • HTML for People: approachable introduction to making your own website.
  • web.dev Learn: accessibility, responsive design, forms and performance.
  • Pro Git: free version-control book.
  • GitHub Skills: interactive GitHub lessons.

Tools you actually need

A text editor (VS Code or your preferred editor), a browser with devtools, and a way to upload or commit files. Markdown is useful for posts. CSS and HTML are essential for custom sites. JavaScript is optional unless a feature needs it.

Preview locally and validate markup with the Nu HTML Checker. CSS can be checked using the W3C CSS validator.

Avoid common rabbit holes

Don't learn React, databases, containers and continuous integration just to put a paragraph online. Learn tools when you hit a real limitation. A lean handmade site can be more reliable than an elaborate stack you can't maintain.
