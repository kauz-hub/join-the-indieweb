11. Neocities, Nekoweb and Bear Blog

These are three excellent places to begin, but they solve different problems. Choose based on what you want to make, not on which community has the prettiest websites.

Neocities Nekoweb Bear Blog
Type Static website host Static website host Managed blog
Main workflow Edit/upload HTML and CSS Edit/upload HTML and CSS Write Markdown posts and pages
Best for Handmade homepages and learning HTML Creative layouts and small-web community Writers who want a simple blog
Design freedom High High CSS customization within a blog structure
First URL Provider subdomain Provider subdomain Provider subdomain
What to check Storage, file types, custom domains Storage, domain and donor features Domain, customization, plan and export options

Neocities

Visit neocities.org and explore the site directory. The platform is especially useful for learning HTML through experimentation and meeting other personal-site creators.

  1. Create a site and choose a memorable username.
  2. Work through the interactive HTML and CSS tutorials.
  3. Edit your homepage and add a short introduction and links.
  4. Add an About page, a diary and a stylesheet when you're ready.
  5. Keep copies of your files locally. Check the current supporter plan if you want additional hosting features or your own domain.

Nekoweb

Visit nekoweb.org and browse the sites hosted there. Its focus is creative, handmade personal websites. It has a file management and import workflow, with additional deployment methods offered under donor plans.

  1. Create your site and open its dashboard.
  2. Upload or edit index.html and add any CSS and images.
  3. Browse other users' sites for ideas and create a personal layout.
  4. Read the host's current FAQ and terms before choosing paid features.
  5. Export copies of your site regularly. If moving from another static host, inspect the archive and keep file paths intact.

Bear Blog

Visit bearblog.dev and read the official documentation. Bear is a good choice when you'd rather spend your time writing than building a website from scratch.

  1. Create a blog and configure its name and homepage.
  2. Write a first post using Markdown and publish it.
  3. Add a few pages and navigation links from the blog settings.
  4. Customize colors, fonts and CSS when you feel comfortable.
  5. Find your feed link and subscribe to other blogs. Check domain and export options in the official docs and current plan details.

You can use more than one

For example, use Neocities or Nekoweb for a handmade homepage and Bear Blog for writing. Link between them and choose a main web address. A separate blog subdomain can make future moves easier if you control the domain. Or keep everything in one place if that feels simpler.

Other creative page builders worth exploring: Carrd, mmm.page, Multiverse and omg.lol. Review portability and publishing limits.
