Welcome!

This site is a collection of things to read and try if you're curious about the IndieWeb. It started as a GitHub repo and now has its own little home.

There's information here on starting a blog, making a personal website, reading RSS feeds and finding other sites. Most of it is aimed at beginners.

If you've never heard of the IndieWeb before, read this first.
