# 14. The personal web toolkit

[Home](../README.md) · [Inspiration](../INSPIRATION.md)

There are many little ways to make a website feel like yours. Start with what you need and add features as you go. Avoid making every page depend on an external widget.

| I want to… | Services and resources to explore |
|---|---|
| Let visitors leave a message | [Meadowing guestbooks](https://guestbooks.meadowing.club/), [SmartGB](https://www.smartgb.com/), [Komments](https://komments.cloud/) |
| Receive messages without showing my email | [Letterbird](https://letterbird.co/) or a contact address I can moderate |
| Share a profile or collection of links | [LinkStack](https://linkstack.org/), [Linktree](https://linktr.ee/), [omg.lol](https://home.omg.lol/) |
| Share favorite albums | [Album Whale](https://albumwhale.com/) |
| Keep my own images online | Your host's file storage, [Picsur](https://picsur.org/) or [Postimages](https://postimages.org/); save original photos locally |
| Accept optional reader support | [Ko-fi](https://ko-fi.com/) |
| Find web design and HTML ideas | [sadgrl.online archive](https://goblin-heart.net/sadgrl), [32-Bit Cafe resources](https://32bit.cafe/resources/) |
| Collect little web buttons | [Capstasher's 88×31 collection](https://capstasher.neocities.org/88x31collection-page1); check reuse terms |
| Explore visual inspiration | [Public Work](https://public.work/), [Inspiration gallery](../INSPIRATION.md); verify individual image rights |
| Mark handmade work | [Human Made Mark](https://humanmademark.com/); read usage terms |
| Create a small web-based start page | [start.me](https://start.me/) or a personal bookmarks page |
| Find independent code hosting | [Codeberg](https://codeberg.org/), [Forgejo](https://forgejo.org/), [GitHub](https://github.com/) |

External guestbooks and comments require a service or backend to save messages. HTML alone cannot save messages shared between visitors. Moderate messages, check spam controls and decide what personal data gets collected. If you use image hosting, preserve your own originals and avoid depending on external URLs for irreplaceable media.

## Creative extras to build yourself

- A blogroll, status page, now page, reading log or music list.
- A changelog that records what changed on the site.
- A small shrine for a favorite album, film, game or character.
- An accessible photo gallery, scrapbook or artwork archive.
- A page of small buttons that link to friends' websites.
- A contact page, colophon or guestbook powered by a chosen service.

## Keep your tools portable

Before adding an embed or external service, find out whether you can export your data, how the company earns money, what visitors must share, whether it loads scripts on your pages and what happens if it shuts down. Sometimes an ordinary HTML link or an email address is enough.
