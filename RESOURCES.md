# Resource directory

[Back to the guide](README.md)

A curated starting point. Prefer official docs for setup and current plan details. The guide does not rank services by sponsorship or promise that a particular service will stay free forever.

## Essential reading

- [IndieWeb home](https://indieweb.org/): the community and its purpose.
- [Getting Started](https://indieweb.org/Getting_Started): domain, hosting, identity and publishing basics.
- [Principles](https://indieweb.org/principles): core practices.
- [IndieWeb projects](https://indieweb.org/projects): software and implementations.
- [Specifications](https://indieweb.org/specifications): standards overview.
- [MDN Learn](https://developer.mozilla.org/en-US/docs/Learn_web_development): foundational web development.

## Validation and quality

- [Nu HTML Checker](https://validator.w3.org/nu/): validate HTML.
- [CSS validator](https://jigsaw.w3.org/css-validator/): check CSS.
- [Feed validator](https://validator.w3.org/feed/): validate RSS and Atom.
- [IndieWebify.me](https://indiewebify.me/): test IndieWeb markup and identity setup.
- [microformats.io](https://microformats.io/): inspect structured HTML data.
- [PageSpeed Insights](https://pagespeed.web.dev/): performance diagnostics.
- [WAVE](https://wave.webaim.org/): accessibility evaluation.
- [W3C WAI](https://www.w3.org/WAI/): accessibility standards and guidance.

## Services and community

- [Webmention.io](https://webmention.io/): hosted receiving endpoint.
- [Bridgy](https://brid.gy/): supported social-site connections and backfeed.
- [Bridgy Fed](https://fed.brid.gy/): federation bridge.
- [Quill](https://quill.p3k.io/): Micropub client.
- [IndieWeb chat](https://indieweb.org/discuss) and [events](https://indieweb.org/events): get help and meet people.
- [32-Bit Cafe](https://32bit.cafe/): personal web community and resources.
- [ooh.directory](https://ooh.directory/): discover blogs.
- [Wiby](https://wiby.me/): discover small websites.
- [Internet Archive](https://archive.org/): historical web and digital collections.
