# 5. Build your personal site

[Home](../README.md) · [Next: feeds and publishing](06-publishing-and-feeds.md)

Start with a home page and the things you have to say. Add separate pages when a section grows into something readers might want to visit independently.

## Things you can make

| Page | What to put there |
|---|---|
| Home | Welcome, navigation and highlights |
| About / me | Who you are, interests, optional contact details |
| Blog / journal | Longer writing and permanent post links |
| Notes | Short updates, thoughts and bookmarks |
| Now | What you're focusing on lately ([nownownow.com](https://nownownow.com/)) |
| Uses | Tools and equipment you use ([uses.tech](https://uses.tech/)) |
| Blogroll | Sites you read and recommend |
| Projects | Work you make and want to share |
| Gallery / collections | Artwork, photos, playlists, hobbies, shrines |
| Contact / guestbook | How to reach you, within your privacy boundaries |
| Colophon | How your site is made and maintained |
| Site information | Accessibility, content policy, credits, license |

## Organize the files

You might keep `index.html`, `about.html`, `blog.html`, `blog/first-post.html`, `links.html`, `style.css` and `images/`. This is just an example file plan, not a theme or template.

Use descriptive permanent URLs. Link to the original post rather than a feed page. Keep navigation consistent. Make the title of each page useful when saved as a bookmark. A custom 404 page helps people find their way if a link breaks.

## Design for readers

- Start with readable text, comfortable spacing and a clear heading structure.
- Use real links for navigation and buttons for actions.
- Keep links recognizable and keyboard focus visible.
- Make images flexible and provide useful alt text when they convey meaning.
- Test on a narrow screen and with JavaScript disabled if your site should work without it.
- Respect reduced-motion preferences. Avoid auto-playing sound and flashing effects.

Personal expression is the point. You can have a retro homepage, a minimal blog or an illustrated notebook. Build something you enjoy looking after.

## Writing ideas

Write an introduction, a reading list, a monthly update, a hobby tutorial, a review of a favorite record or a note about building your site. A public site can be deliberately small. You don't owe anyone constant content.
