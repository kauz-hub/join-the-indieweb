2. Choose a platform

Pick the platform that makes publishing easiest for you. You can move later if your content and domain are portable.

Static hosting

Static hosts serve HTML, CSS, JavaScript and images. They usually don't run a database or server-side scripts for you.

Option Workflow
Neocities Edit or upload files through a web interface. Great for handmade homepages.
Nekoweb Small-web-focused static hosting.
GitHub Pages Store files in Git and publish from a repository.
Codeberg Pages Static publishing with the nonprofit Codeberg forge. Read current git-pages setup instructions and eligibility.
GitLab Pages Publish from a GitLab project using CI.
Cloudflare Pages Upload or build a static project with Git integration.
Netlify Git deployments or manual uploads.

Check current limits on bandwidth, storage, custom domains, build minutes and acceptable use. Some free tiers are enough for a personal site, while custom domains or added features may require payment.

Static site generators

Once copying HTML for each post becomes tedious, a generator can turn Markdown and shared layouts into HTML files.

  • Eleventy: flexible JavaScript-based generator.
  • Hugo: standalone binary, themes and Go templates.
  • Jekyll: Markdown, Liquid and Ruby, with a long history on GitHub Pages.
  • Astro: component-based content sites with optional interactivity.
  • Zola: standalone Rust-based generator.

Generators are not hosting services. Keep source content and build configuration as well as published output.

Dynamic CMS and self-hosting

WordPress.org, Ghost and Known can manage posts and dynamic features. Managed hosting reduces operational work. A VPS gives more control but requires keeping the OS, applications, certificates and backups healthy.

For WordPress, read the IndieWeb WordPress walkthrough. Check plugin and theme compatibility before installing anything.

Decision checklist

Before paying for anything, ask:

  • Can I use a domain I control? Can I export posts, images and redirects?
  • Can readers subscribe without an account?
  • Can I publish what matters to me without changing my workflow every month?
  • Is the price sustainable after any introductory offer?
  • Can I leave without losing my address or years of work?

If you're still unsure, try a free hosted page or blog and publish something before researching more platforms.
